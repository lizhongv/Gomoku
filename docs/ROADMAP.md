# 路线图与待办

> 更新时间：2026-11-01
> 状态说明：已完成 / 进行中 / 待排期。版本号遵循语义化版本，破坏性改动升主版本。

## v2.0（已完成）

- 规则内核：15/19 路、无禁手与连珠禁手、棋型识别、Zobrist、胜和判定。
- 搜索引擎：迭代加深、置换表、Killer/历史、VCF、12 档难度、教练接口。
- 桌面客户端：对局、悔棋、提示、复盘、残局、设置、三套主题、中英双语、内置音效。
- 联机：服务端权威裁决、房间、快速匹配、断线重连、ELO、每手限时、TLS、验证码、登录锁定。
- 工程：多模块 Maven、CI、静态检查、覆盖率门槛、三平台安装包。

## 技术债

- 迁移期的 `gomoku-legacy` 在 v2.0 稳定后删除。
- TLS 仅实现代码路径，尚未用真实证书端到端联调。
- 协议版本兼容策略需在首次破坏性变更前补测试。
- 客户端 i18n 尚未覆盖错误提示与协议错误码。

## 暂不纳入

以下能力属于电商/中台类产品，不属于五子棋产品范围，未纳入本仓库路线图：
微信支付/支付宝、短信与物流、拼团砍价分销、小程序商城、Elasticsearch 商品搜索等。
如另有商城项目，应单独立项，不要把两套产品的待办混在同一仓库。
